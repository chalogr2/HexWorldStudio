# Hex World Studio

A procedural hex world generator for Unity. Builds Civ-style hex maps — continents, biomes, rivers, resources, starting positions — with a code-first runtime API and a polished custom editor.

**Status:** Pre-alpha. Repository scaffolding only. No generator code yet.

**Target buyer:** Unity developers building 4X, turn-based strategy, or hex-grid games who want a deterministic, ScriptableObject-driven world-generation foundation so they can focus on gameplay.

**Engine:** Unity 6.0 LTS (URP). Minimum supported editor: `6000.0.58f2`.

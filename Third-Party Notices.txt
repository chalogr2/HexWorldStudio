Third-Party Notices
===================

Hex World Studio includes the following third-party works. Each entry
lists the original work, its author, its license, where it lives in the
repository, and any changes made to it.

When adding a new third-party item to the repository, append a new entry
to this file following the same template.

----------------------------------------------------------------------

1. Kenney Hexagon Kit
   --------------------
   Author:           Kenney (https://kenney.nl)
   Original work:    Hexagon Kit
   Original source:  https://kenney.nl/assets/hexagon-kit
   License:          Creative Commons Zero v1.0 Universal (CC0 1.0)
                     https://creativecommons.org/publicdomain/zero/1.0/
   Location:         Assets/HexWorldStudio/ThirdParty/Kenney Hexagon/
   Modifications:    Models are included as downloaded (FBX, GLB and OBJ
                     formats, shared textures, preview images). The
                     Materials/ folder holds URP materials made for this
                     project and applied to the kit's meshes. Tile and
                     feature prefabs under
                     Assets/HexWorldStudio/Content/Prefabs/ are built from
                     these models.

----------------------------------------------------------------------
